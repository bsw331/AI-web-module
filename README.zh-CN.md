# 知问 AI 聊天界面

一个轻量、单文件的 AI 聊天界面。配置 API Key、模型和 API 地址后，即可连接支持 OpenAI 兼容 Chat Completions API 与 SSE 流式响应的服务。

界面支持简体中文和英文。

## 功能

- 单个 HTML 文件，无需构建步骤、额外依赖或后端服务。
- 支持配置 OpenAI 兼容的 API 地址、模型名称和 API Key。
- 支持流式回复、对话上下文和快捷提问。
- 支持简体中文与英文切换，并记住语言偏好。
- API Key 仅保存在当前页面内存中，刷新或关闭页面后会清除。

## 快速开始

1. 下载或克隆本项目。
2. 使用现代浏览器打开 `index.html`。如果服务商不允许从 `file://` 页面发起请求，请改用本地 Web 服务器提供该文件。
3. 点击 **API 设置**，填写 API Key、模型名称和聊天补全接口地址。
4. 保存设置并开始聊天。

默认模型为 `gpt-4o-mini`，默认接口地址为 `https://api.openai.com/v1/chat/completions`。请根据所使用的服务商修改配置。

## API 兼容要求

配置的接口需要接受 `POST` 请求，请求 JSON 包含 `model`、`messages` 和 `stream: true`，并返回 OpenAI 兼容的流式响应。页面会在 `Authorization` 请求头中以 Bearer Token 方式发送 API Key。

由于请求由浏览器直接发起，服务商需要在 CORS 跨域策略中允许当前页面的来源。即使接口地址和密钥正确，网络或 CORS 限制也可能阻止请求。

## 安全说明

- 本项目是纯浏览器客户端，不是安全代理。API Key 会发送到你配置的接口，并可能被页面中的脚本访问。请只在可信的页面和设备中使用。
- API Key 不会写入浏览器存储；它只在当前页面内存中保留，刷新或关闭页面后会清除。
- 模型名称和 API 地址会保存在当前浏览器的 `localStorage` 中。
- 请勿将包含个人 API Key 的页面副本发布到公开环境。若要公开部署或供多人使用，请通过后端保护密钥并实施访问控制。
